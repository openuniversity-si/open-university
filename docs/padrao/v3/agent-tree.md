# Agent tree (Daniel 00:53)

The main session (PR) is only the coordinator: it launches each PR stage, reads the summarized result, approves or sends back, commits/pushes (sole writer of the branch), and opens/readies/merges the PR. Level 1: one sub-agent per PR stage (audit, plan, execution, gate, retro); stages run in dependency order. Level 2: inside each stage, parallel sub-agents for independent parts (audit: one per area such as code, contracts, tests, config, known defects and lessons; plan: one per step mini-brief; execution: one per plan.md commit, run per the plan graph; retro: one per phase). Level 3: inside an execution commit, parallel sub-agents for independent parts (e.g. code, tests, docs). Claude Code allows 3 nested layers and 20 concurrent sub-agents per session; stay within that. Each sub-agent gets only its own mini-brief as context and returns a short summary; sub-agents never commit.
