# Think before acting (Daniel, Oct 26 22:41)

Before any action that costs time or quota (rerunning a suite, a gate, a relaunch, a big change), stop and answer: (1) what exactly do I need to know or achieve? (2) what are the possible ways, with the cost and time of each (read the diff, read gate output, run the single suspect test locally, compare against the base)? (3) which is the cheapest and fastest that answers it? Then act, and state the choice and why in one line in your PR comment. Never default to the heaviest path by reflex.
