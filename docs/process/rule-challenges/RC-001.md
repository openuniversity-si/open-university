# RC-001 — the designated branch name versus a stale remote branch
- Grade: 2
- Status: changed
- Rule: "Develop on the designated branch `claude/fluxo-amplo-v8-avaliacao-3m6zlh`; never push to a different branch without explicit permission" (session instructions), with "push-guard and the literal census compare a push with its remote branch".
- Evidence: the remote branch already existed at `251b64fb` (PR #666, 27/10), entirely inside `origin/main`, 2,688 commits behind the base. The push was refused by the literal census, which judged against the merge-base `198aa130` with that stale branch, so every engine file looked new (`FAIL engine-battery: number 10 is written 1 times ... allows 0`). A `--force-with-lease` was denied by the permission classifier.
- Harm: the first push of FLUXO-AMPLO was blocked for several minutes of the 31/10 afternoon (first refusal about 14:58 BRT); the session could not open its draft PR, the first step of every unit.
- Proposal: when the designated branch exists and is stale, the launcher resets it to the base (or the pre-push takes its census base from the PR base, not from the push target's upstream); until then, a session may push to a new `claude/<unit>-*` name after the watchman's say.
- Impact: touches only branch names of one unit; reversible; no production, money or other people.
- Decision: Daniel, 31/10 afternoon (BRT), in chat: no force-push; push `HEAD` to the new branch `claude/fluxo-amplo-v8-f1` (and, if that name also fails, another new `claude/fluxo-amplo-v8-*` name without asking).
