# RC-006 — lane-ship stops every lap on a conflict beyond DECISIONS.md
- Grade: 2
- Status: upheld
- Rule: scripts/lib/lane_ship.py (docstring) and docs/process/lane.md: a conflict in `docs/domain/DECISIONS.md` keeps both sides' rows; any other conflict stops the lap.
- Evidence: in this session, four PRs stopped on the base merge: #1006 (docs/operations/incidents.md, docs/process/repeats.md, scripts/lib/repeats.py, scripts/lib/usage.py, scripts/tests/test_repeats.py); #980 (scripts/tests/covers/generate-tree.json); #962 (docs/programs/fluxo-amplo/plan.md, docs/structure/assets.json); #932 (docs/structure/assets.json). `git merge-tree` on #932 shows a content conflict in docs/structure/assets.json, while docs/domain/DECISIONS.md and CODEOWNERS auto-merge. Each stop left a merge in progress, aborted by hand (`git merge --abort`), so the branch stayed at its pushed head.
- Harm: four of the seven integrations of this session stopped. Each stop costs a lap and a manual abort, and the PR waits for a person to resolve a manifest that both sides extended.
- Proposal: keep both sides for append-only manifests, meaning JSON lists where both sides only add entries (for example docs/structure/assets.json and the covers manifests), and let the structure check judge the union; keep stopping for conflicts in prose and code (plan.md, repeats.py, usage.py, test_repeats.py), which need a person.
- Impact: lane-ship in unit engine-flow (lane 1). A wrong union in a manifest is caught by the structure check before the gate. Reversible: one function in one file.
