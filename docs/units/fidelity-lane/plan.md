# U3b plan: fidelity lane imports to `@ou` addresses

Source: docs/units/fidelity-lane/audit.md. Mechanical PR (plan v3.1 §4: U3b lanes are Haiku). No file moves, no
renames, no behaviour change.

## Scope decision

Rewrite only the cross-unit specifiers in files that no Node entry point loads. Every other one stays relative and is
a recorded contract gap. Reason: the fidelity scripts run lane files with `node <file>.ts`, and Node cannot resolve
`@ou/` (D-069 item 7; same decision as commits 3c0ffb84 and 2d7d70e2 of the U3b precedents).

| File | Owner | Cross-unit specifiers | Action |
|---|---|---|---|
| `apps/web/fidelity/references/references.test.ts` | fidelity-references | `../../src/platform/db/tooling/index.ts` (type) | rewrite to `@ou/db-operations/tooling/index.ts` |
| `apps/web/fidelity/references/references.int.test.ts` | fidelity-references | `../../src/platform/db/operations/index.ts`, `../../src/platform/db/tooling/index.ts` | rewrite to `@ou/db-operations/operations/index.ts`, `@ou/db-operations/tooling/index.ts` |
| `apps/web/fidelity/resolve.test.ts` | fidelity-runner | `./references/active.ts` (type) | rewrite to `@ou/fidelity-references/active.ts` |
| the other 19 lane files (Node closure) | both | 22 specifiers | stay relative (contract gap for the Node path) |

Imports inside one unit stay as they are (`./compare.ts`, `./active.ts` and the like).

## Premises and blast radius

- P-03 (confirmed, high): units are imported only through `@ou/<id>`. Radius high. If wrong (the map does not resolve
  `@ou/db-operations/*` to the files), the rewritten tests fail to load; the check is `unit_addresses.check` and the
  vitest run.
- P-13 (inferred, medium): one lane owns a unit at a time. The PR touches only lane-owned files
  (`scripts/units owner`), so no other lane is affected.
- Node cannot resolve `@ou/` (verified by construction: bare specifiers need a package, and Node reads no tsconfig
  `paths`). Radius: 19 files. Not changed here; left relative. If a Node resolver lands later, the gap closes in a
  follow-up.

No CRITICAL premise: no production, no secret, no source-of-truth change.
