# config-theme contract (1.0.0)

The unit is logical (S1, P-03). Its surface is the two generated modules below; no `index.ts` re-export is added (D-029), so the manifest `contract` slot stays empty. Importers keep `@ou/config-theme/<file>`.

| Module | Exports other units import |
|---|---|
| `values.ts` | `towerBreakpointDesktop`, `towerBreakpointPresent`, `towerBreakpointTablet`, `towerBreakpointWide`, `towerCourseAboutWidth`, `towerCourseColumnGap`, `towerCourseThumbWidth`, `towerLayoutGutterDesktop`, `towerLayoutGutterMobile`, `towerLayoutGutterTablet`, `towerLessonStageInset`, `towerPosterNearMargin`, `towerSurface`, `towerViewportWidth`, and (namespace import by config-documents) every `tower*` value |
| `names.ts` | `themeTokenNames` |

Every other export is internal. The files are regenerated by `pnpm tokens:generate`; a token removed from the Figma snapshot is a breaking change and goes expand->contract (P-07, D-029): move callers, then regenerate. No consumer file is edited here.

Literals: none tunable (generated D-063 catalogs). UI text: none. Battery: `scripts/unit-battery config-theme`, limit `battery.unit_time_limit`.
