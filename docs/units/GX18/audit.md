# GX-18 audit

Base tip 3cae824a (mod/roadmap-integration). Everything below is the current behaviour the unit changes.

1. **The docs area runs no script test.** `scripts/lib/gate-areas.json` area `docs` (`"id": "docs"`, `paths` docs/**, **/*.md, **/*.txt, **/*.rst) has `"groups": []`. A docs-only diff therefore plans only the `always` stages; `script tests` is skipped (`test_gate_areas.py::test_table` "docs-only" expects `picked(SECRETS)`).
2. **Documentation wins over every other area.** `gate_areas.py` `AreaMap.areas_for` returns only the `docs` area when `is_documentation(path)` (prefix `docs/` or suffix .md/.txt/.rst), so a markdown file under `scripts/` or `config/` also gets no script tests.
3. **Several script tests read docs** (G-15), declared in `scripts/tests/covers/*.json` (read via `gate_script_tests.load()`): `event-contracts` covers `docs/process/EVENTS.md`; `lessons` covers `docs/units/*/retro.md`, `docs/process/lessons/*`, `docs/process/lessons.md`; the program, units and premises tests cover `docs/programs/**`, DECISIONS.md and `docs/process/premises/*.yml` (checked in the fixtures of this unit). A docs-only PR that breaks them is not caught until the nightly.
4. **Selection by covers already exists, per path.** `gate_script_tests.select(paths)` (`gate_script_tests.py`, `select`) returns the tests whose covers match each owned path; a path counts as owned if it starts with `scripts/` or is covered; an uncovered `scripts/` path or no owned path at all returns the full suite ("no scripts path; full script suite"). `gate-local` runs it for the `script tests` stage (`run_script_tests`, scripts/gate-local:324-374) with `GATE_PLAN_FILE`. So the stage can simply be added to the docs plan only when some docs path is covered; `select` then picks exactly the covering tests. If the docs plan added the stage unconditionally, `select` would return the full suite for an uncovered docs diff (item above), which is wrong.
5. **Stage choice is per area, not per path.** `Area.stages(groups)` and `plan_for` (gate_areas.py) add every stage of every group of an area. There is no per-path condition, so the filter needs a small seam: an area key naming groups that apply only to paths covered by a script test.
6. **Fail closed.** `gate_script_tests.load()` raises `ScriptTestMapError` when a sidecar is missing/invalid; `gate_areas` must not swallow that into "skip": on any failure the docs path selects the `script-tests` group (P-10). `gate_script_tests` imports `gate_areas.glob_match`, so `gate_areas` imports it lazily.
7. Edge: a docs-only diff mixing a covered doc with an uncovered `scripts/*.md` makes `select` return the full suite (uncovered scripts path). Over-runs, never under-runs; accepted.
8. Under the pinned gate the covers come from the base tip tooling; a head that adds a new sidecar for a doc is seen after it merges.
