# RETRO: U4 engine-capture

1. **Brief quality.** The brief asked for a manifest `contract` and a unit battery, but both assume an `@ou` address, which no `scripts/` unit has; the brief's own fallback ("keep the files in place") did not say what to do with the contract. It also said the no-literals allowlist "shrinks to zero", but the checker only judges registered names, so the unit had no listed literals to shrink; the real literals (timeouts, viewports, URLs, flags) were invisible to it.
2. **Audit and plan.** Held: P-03 (files stay in place), P-05. Broke: the contract step. Plan changed after commit 2 (contract in `contract.md`, not the manifest) and `plan.md` was updated.
3. **Execution.** Failures and classes: (a) `media-parity.mjs` already had a function named `capture` (name clash with the reader; fixed by importing it as `setting`); (b) the first reader loaded 17 settings in one call, which costs about 0.25 s per name in `config.py`, so the battery ran 20.9 s against the 10 s limit; fixed with a lazy per-setting read (7.5 s). The class (a settings reader whose cost scales with the registry) belongs to engine-config: `config.py get` replays the change store per name. A `pkill -f gate` also killed the shell that ran it. Dead ends: none beyond these.
4. **Gate.** See the PR comment. Known base defects hit: Playwright pins chromium 1248 and the cloud image has 1243, so browser tests (`production-capture` test 3) hang locally and are left to the gate's e2e stage; `scripts/generate intents` fails locally (`apps/web/scripts/intents-doc.ts` module not found), unrelated to this unit.
5. **Lessons.** (a) `config.py get` with many names should read the store once (owner engine-config); (b) the unit battery's contract step should accept units without an address, or the unit schema should say a `scripts/` unit declares its contract elsewhere (owner engine-battery); (c) the brief template should say how a unit with no address gets a contract (owner coordinator); (d) the no-literals check should list tunables of non-registered names in unit files so "zero" is measurable (owner engine-config).
