**AGENT-ENV, one source of truth for what each agent execution environment receives (decided by the session under D-325, at Daniel's request through the Torre).** Each agent execution environment is declared in config/agent-env/<id>.json, validated by contracts/agent-env/environment.v1.json: its provider, its non-secret variables, its secrets by name only, its network hosts and its one starting credential. A secret is declared by name and reference, never by value, under /tower/agent-env/<id>/ (SSM SecureString, the default, free) or tower/agent-env/<id>/ (Secrets Manager, only where a secret already lives there). At session start the environment receives what it declares from an authenticated AWS endpoint, using its one starting credential, given by hand once; a new provider (Google Antigravity next) is one declaration. The Torre's webhook is reached only through a relay whose role alone reads tower/torre-webhook-key and tower/torre-webhook-url, so a session calls the Torre without ever seeing the key. Deny list: the names the engine never sends to a cloud agent, as AGENTS.md Cloud setup requires (the site's hosting and database tokens, database URLs, R2 keys, AUTH_*, OU_GOOGLE_*, Mux, Figma and blob tokens), are refused by the validator, by the delivery and by the client. The-tower's starting credential is TOWER_EVENTS_TOKEN, already in the environment: the Torre stores its sha256 once in SSM and AWS checks against that, with no other service involved; it once belonged to the retired control plane (D-323), and its value is just a shared secret now. Least privilege per environment: each environment's role reads only its own prefix, and every delivery is audited. Cost: about US$1 a month (two Secrets Manager secrets at US$0.40, SSM standard free, Lambda and HTTP API under US$0.05) against REQ-aws-200. This first step is the model only (the contract, the declarations, the deny list and the validator); no AWS change. Alternative not taken: keep each environment's variables set by hand per provider, which gives no audit, no single deny list and one more hand step per provider. Revert path: delete the declarations; the environments go back to hand-set variables.
