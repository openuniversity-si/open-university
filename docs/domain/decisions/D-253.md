A commit whose body carries a `Gate-fix:` line, on the same Plan item and the same files as the commit before it, is the same unit of work and is not counted as split (classify in scripts/lib/flow_metrics.py, lane 1's unit). Without the line the rule is unchanged: the same item on the same files stays split. Evidence: test_flow_metrics.py, GateFix: a Gate-fix commit on the same item and file is not split, and the same commit without the line is split; the trailer is read from the commit body. Both fail without the change.
