**Andon on main stops promotion, never the merge queue: `main-health` is not installed as a required gate job; a confirmed red `full-suite` on main is surfaced as one `main-red-andon` issue and refuses the site release of that commit (Torre por delegação do Daniel 22/11/2026; Daniel 23/11/2026 11:36 BRT, t4488u: "Pode seguir"; builds on D-359 (2), D-087, D-054).** The staged `main-health` job (`services/runner/github/proposed/tower-gate.yml`, D-359 Salto 2) would make every non-`fix-main` PR fail `tower/gate` while the newest `full-suite` on the base is red or an Andon issue is open. Judged harmful as designed and not installed: (1) a flake turns `full-suite` red and freezes every merge, and the run that would turn it green again needs a merge on main (or a manual re-run), so the queue deadlocks on noise; (2) `full-suite` takes about six minutes after each merge, so a PR's check races its base's suite; (3) on 19/11 the reds came in a run of merges that carried the repairs themselves, which the freeze would have made wait on a label. Instead: (a) **promotion stops** — the site image is built only for a commit whose newest `full-suite` run on that exact SHA succeeded (`scripts/workflow-attest promotion-health`, run by `apps/web/deploy/promotion-guard.sh` from `build-image.sh` when `BUILD_SHA` is set); red refuses, running or absent is not decided (the Torre releases after green; no polling), and a flake is cleared by re-running the suite, whose newer run decides; (b) **surfacing** — `full-suite.yml` keeps a single deduplicated `main-red-andon` issue (opened on a confirmed red, commented on each further red, closed by the next green), installed by the Torre in a separate workflow PR (D-087). The engine deploy (`deploy-doorbell`, QUEUE-RELOAD) is not gated: its code-only landing reloads in place within REQ-deploy-1s through GitHub's push webhook, and the engine build has its own smoke. `full-suite` already re-runs each red test alone before failing (VERIFY-ALONE), so its red is a confirmed red. Residual: an anonymous read of the check runs past GitHub's per-address limit refuses a release (fail closed), which the Torre starts again. Revert path: remove the guard call from `build-image.sh` via a PR; record a superseding decision by an independent approver (Torre or owner), or by Daniel for money or other people.
