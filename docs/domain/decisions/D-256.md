Duplicate ids in the register: when two rows of DECISIONS.md carry one id, the earlier row keeps it and the later row (by its time) takes the next free number; each reference that names the later row is renamed with it, and the earlier row's references stay. D-165, D-166, D-167 and D-173 are the cases: D-243, D-245, D-246 and D-247 are the renumbered rows. decision-table --check refuses an id written twice, and a test reads the live register.
