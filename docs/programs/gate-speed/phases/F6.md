# gate-speed — F6: ≤ 60 s

Phase 6 of the [solução](../solucao.md) (D-122: the rest by measured share). F5 left the suite at 94.9 s cold on
4 vCPUs and 310.5 CPU-s ([F5](F5.md)).

## Auditoria
Measured on F5's head in the session container:
1. **The wall waits on single files.** `cpu_s / 4` is 77.6 s and the wall 94.9 s: about 17 s of a cold run is a
   tail in which a few long files run alone while the other CPUs idle. A test file is one process and runs its classes
   one after the other: `train.test.sh` (about 60 s in a cold run) ends with `train/test_verdict.py` (six classes,
   14.8 s alone), `train-reuse.test.sh` runs `test_train_reuse.py` (six classes, 13.7 s) and `train-role.test.sh`
   `test_train_role.py` (six classes, 8.1 s) as single processes. The jobserver (F1) lends a freed CPU to a running
   script test, but a test can spend it only on another file. The system that fails: the unit of parallelism is the
   file, and a file grows by classes.
2. **Every config read stats the whole registry** (about 130 µs: 60 files) unless it runs inside `config.reading()`;
   `test_config_api.py` alone made 153,000 such checks. No cheaper signature is safe while a test may rewrite a
   registry file in place, so this phase leaves it.

## Plano
| Root | Alternative | Level | Choice |
|---|---|---|---|
| 1 | A1: split the long files by hand | remendo | no: the next file grows again |
| 1 | A2: `parallel_tests` runs one process per TestCase class of a plain unittest module (it ends in `unittest.main()` and has no `load_tests`) whenever it has more than one CPU, so the jobserver spreads classes; the long single-file scripts (`train-reuse`, `train-role`, `merge-regenerate`) run through it | corrige a classe | **yes** |
| 1 | A3: one process per test case from a warm fork (pytest-xdist's model) | redesenho | later: fixtures per case cost more than the gain at this size |
| 2 | — | — | left: no cheaper check is safe while a test may rewrite a registry file in place |

Built and measured on a worktree of F5's head, not merged (D-125): the class runs, a run's wall per file written by
`parallel_tests` into the committed hints, each script test's files longest first, and the split kept to files whose
hint reaches 15 s (`train/test_verdict.py` and `test_train_reuse.py`, 16.8 s each in a cold pass).
